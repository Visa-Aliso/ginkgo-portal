# 银杏与风

[English](README.md) | 简体中文

一个独立的个人导航页。折叠文章摘页、名片与随笔纸页分别连接 Blog、Profile、Notes。保留白色 / 深色 / 跟随系统三种外观，以及可被鼠标和触碰吹开的银杏落叶。

## 本地运行

需要 Node.js 22.12 或以上版本。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。生产构建与本地检查：

```sh
npm run check
npm test
npm run verify
npm run build
npm run preview
```

构建输出为 `dist/`，可以上传到静态网站托管或自己的服务器，也支持部署到子目录。页面不依赖服务器接口、账号或第三方字体服务。

## 配置

日常修改使用独立的 JSON 格式 `.config` 文件，所有字段名和字符串需用双引号，不写注释或尾逗号。`config/site.config` 管理站点、主题与动画，`config/profile.config` 管理个人资料，`config/notes.config` 管理随笔页文案和落叶密度。字段说明见 [配置指南](docs/configuration.md)。保存后开发页自动重载；发布前重新构建。Notes 默认连接到 `./notes.html`，Profile 连接到 `./profile.html`，Blog 地址留空：正常点击会完整预览展开动画，再返回入口。支持相对路径或完整 `https://` 地址，同一动画结束时会跳转。链接保留键盘访问、右键菜单和 Ctrl / Command 点击的原生行为。

| 配置                     | 默认值   | 含义                                 |
| ------------------------ | -------- | ------------------------------------ |
| `name`                   | `Ginkgo` | 三页共用的左上角站点名，空值使用 Ginkgo |
| `entries.*.url`          | Notes 为 `./notes.html`，Profile 为 `./profile.html`，Blog 为空 | 三个入口的页面路径或独立站点地址 |
| `defaultTheme`           | `system` | 首次访问时的外观；访客选择会优先保存 |
| `leaves.desktopCount`    | 40       | 桌面目标叶子数量                     |
| `leaves.mobileCount`     | 26       | 手机目标叶子数量                     |
| `leaves.refillDelay`     | 4        | 吹散后开始补充的等待秒数             |
| `leaves.refillInterval`  | 0.32     | 相邻叶子重新飘入的间隔秒数           |
| `leaves.breezeSpeed`     | 1        | 自然风速倍率                         |
| `leaves.gustStrength`    | 1        | 点击风力倍率                         |
| `leaves.pointerRadius`   | 90       | 鼠标拨动叶子的影响范围，单位 px      |
| `leaves.clickRadius`     | 225      | 点击吹风范围，手机自动缩小           |
| `leaves.size`            | 1        | 叶子尺寸倍率                         |
| `leaves.maxFps`          | 60       | 叶子绘制频率上限                     |
| `leaves.pixelBudget`     | 1048576  | 前景画布像素预算；越小越省内存       |
| `motion.transitionSpeed` | 1        | 入口动画速度倍率，越大越快           |

颜色在 `src/pages/portal/styles.css` 中集中使用 CSS 变量：`--qp-*` 控制纸页与背景，`--leaf-*` 控制银杏。叶子形状、叶脉和阴影由 Canvas 绘制，无需额外图片。

## 交互与兼容性

- 鼠标经过会轻轻拨动叶子；点击叶子或空白处产生局部风；右上角风按钮清开整页。
- 长按风按钮约 0.7 秒，吹走现有叶子并暂停生成；再次长按恢复。按住时显示进度环，暂停后显示小暂停标记。鼠标、触屏以及键盘按住空格／Enter 均可操作。
- 首页与 Notes 的暂停状态会在这两页之间和刷新后保留；调整窗口、切换主题、浏览器后退也不会恢复生成。浏览器禁止本地存储时，本页仍可暂停与恢复。暂停并清空后不再持续绘制。
- 点到覆盖在入口上的叶子会先吹走叶子，避免误跳转；露出的入口正常响应。
- 空白链接预览结束后回到原位；Escape 可以取消进入动画。
- 主题选择保存在浏览器本地；禁用本地存储时仍可使用。
- 页面不可见时暂停动画；系统开启减少动态效果时停止持续运动，吹风直接清除叶子。
- 手机独立限制叶子数量与绘制像素比，工具按钮提供 44px 触碰区域。

## 随笔页

通过引导页的 Notes 入口或直接访问 `/notes.html` 打开。随笔页沿用冷白色、蓝色纸片、折角和银杏落叶；支持浅色、深色和跟随系统，外观偏好与引导页共享。

- `content/notes/` 存放随笔，一篇一个 `.md` 文件；列表自动读取，按日期从新到旧排列，分类自动生成。
- 分类与搜索可同时使用；搜索覆盖标题、摘要、分类和正文。按 `/` 可聚焦搜索框。
- 点击纸片展开全文；支持上一篇、下一篇、Escape 关闭及 `notes.html#note=文章id` 直达链接。
- 页面注明了示例内容，正式替换后可修改 `notes.html` 页脚的“示例随笔集”文案。
- 页面为静态实现，无在线编辑或发布后台；修改数据后重新执行 `npm run build`，同时发布 `dist/` 内的全部文件。

### 写一篇随笔

复制 `content/notes/_template.md`，重命名为 `my-new-note.md`，改好顶部信息，把 `draft: true` 改为 `draft: false`，然后写正文。以下划线开头的文件及 `draft: true` 的文章不会显示。默认使用文件名作为文章 ID，发布后尽量不要重命名；也可在顶部显式填写 `id` 来固定阅读链接。

```markdown
---
title: 今天的一点小事
date: 2026-11-17
category: 生活观察
excerpt: 这是显示在卡片上的摘要。
animation: unfold
---

这里开始写正文，段落之间空一行。

## 一个小标题

可以写 **加粗文字**、*斜体文字*，也可以插入引用：

> 今天值得记住的一句话。
```

`title`、`date`、`category`、`excerpt` 必填。顶部信息采用简单的单行 `key: value` 格式；需要换行时写 `excerpt: "第一行\n第二行"`，不支持 YAML 多行块或嵌套对象。正文支持段落、标题、粗体、斜体、单层列表、引用、链接、图片、行内代码、围栏代码块和分隔线；不解析原始 HTML，暂不支持表格、嵌套列表或 LaTeX 公式。

图片放进 `public/images/`，正文写 `![图片说明](./images/my-photo.jpg)`。写作时运行 `npm run dev`，修改或新增文章会更新页面；正式发布仍需要重新构建。

### 为每篇随笔选择动画

| `animation` | 打开效果 |
| --- | --- |
| `unfold`（默认） | 从卡片位置倾斜展开，文字随后浮现 |
| `lift` | 纸片轻轻抬起，舒展到阅读位置 |
| `turn` | 纸片侧向翻开，过渡到正文 |
| `fade` | 轻微位移并淡入 |

关闭时收回对应卡片，上一篇／下一篇使用方向过渡；原卡片不可见时采用短距离淡出。系统开启“减少动态效果”时直接显示内容。可选 `style: blue`、`style: landscape`、`style: quote` 分别使用蓝纸、风景插图和摘句卡片；省略时使用普通白纸。

随笔动效使用引导页的 `motion` 配置：`transitionSpeed` 统一控制展开与分类过渡速度，`softness` 控制便笺的弹性，`breeze` 控制悬停时的轻微浮动。默认展开约 420–720ms、收回 420ms、篇目切换 380ms；分类过渡约 450ms，保留原卡片，移动归位并淡入淡出，连续操作会取消过时的动画。鼠标在纸面移动时会倾斜、抬起纸片，带动折角和回形针。

银杏层复用引导页的物理效果：鼠标拨动、点击局部吹风、点击叶子先吹开以免误开文章、风按钮清场及自动补充。随笔页使用较少的叶子以便阅读；页头、分类、搜索和阅读弹窗不拦截操作。触屏保留纵向滚动，不启用鼠标倾斜；减少动态效果时禁用过渡和弹簧运动。

从引导页进入随笔时，蓝色纸片展开至全屏后会由新页面接续，用约 1.4 秒缓慢收拢到第一张蓝色便笺，其余内容依次显现。入口悬停或点击时提前加载本地 Notes 页面资源；使用短时、一次性的会话标记传递纸片颜色，适配明暗主题及子目录部署。直接访问、刷新、减少动态效果及外部站点链接不播放该入场效果；脚本加载失败时遮罩会自动解除。浏览器后退恢复引导页时会清理展开状态。三个页面的样式均通过 HTML 头部直接加载；返回主页时，卡片完成定位后才显现，避免先出现未排版内容。

## 文件结构

| 路径 | 职责 |
| --- | --- |
| `config/*.config` | 独立的站点、Profile、Notes 配置 |
| `content/notes/*.md` | 随笔与写作模板 |
| `src/pages/portal/` | 首页入口、弹簧与导航动效、首页样式 |
| `src/pages/notes/` | 列表、卡片、阅读器、分类与跟手动画 |
| `src/pages/profile/` | 资料渲染、展开收起动画、打印样式 |
| `src/shared/` | 主题、站点字标、DOM、Markdown、首帧与跨页衔接 |
| `src/shared/styles/` | 公共文档布局、工具栏、字标样式 |
| `src/effects/` | 银杏引擎与吹风手势 |
| `src/config/` | 程序内部的类型、校验和配置导入；不在这里填资料 |
| `build/config-plugin.ts` | 将校验后的配置与同步首帧脚本编入页面 |
| `scripts/`、`tests/` | 配置、内容、动画、内存资源及生产产物检查 |

## 检查与发布

`npm run verify` 会先运行全部测试，再进行类型检查、配置校验、随笔内容校验、生产构建与产物检查。非法日期、重复文章 ID、错误动画名、缺少必填字段等会阻止构建，不必等上线后才发现。`npm run preview` 用于人工检查打包后的页面；发布时上传完整的 `dist/`。

实现约定和维护说明见 [docs/architecture.md](docs/architecture.md)。浏览器测试需要检查桌面与触屏的真实手感；自动测试不代替视觉检查。


## Profile 个人主页

通过首页 Profile 或 `./profile.html` 打开。参考 Asipe 的单栏学术简历结构，个人简介之后依次排列教育经历、论文、开源、奖项和项目，不使用侧栏或卡片。资料在 `config/profile.config` 中集中编辑，完整字段示例见 [Profile 配置说明](docs/profile.md)。

此页每次打开默认无银杏叶；右上角风按钮与其他页一致：单击吹风、长按恢复／暂停，暂停时显示同样的“Ⅱ”标记，不修改首页和 Notes 的暂停偏好。主题仍在三页之间共享。打印使用 A4 文档样式，隐藏工具、落叶和按钮，并展开所有条目。内容增加时自然分页。
