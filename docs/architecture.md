# 实现与维护

## 文件边界

站点是 Vite 多页静态应用，`index.html`、`notes.html`、`profile.html` 分别加载自己的入口和 CSS。运行时不需要后端。

| 目录 | 职责 |
| --- | --- |
| `config/` | 用户可直接编辑的 JSON `.config` 文件 |
| `content/notes/` | Markdown 随笔 |
| `src/config/` | 配置类型、校验、导入层，不放具体资料 |
| `src/pages/portal/` | 首页布局与纸张入口动效 |
| `src/pages/notes/` | 列表入口、卡片渲染、阅读器、分类动画、弹簧动画 |
| `src/pages/profile/` | 页面初始化、资料渲染、章节展开动画 |
| `src/shared/` | DOM、主题、偏好、站点字标、Markdown、首帧和跨页过渡 |
| `src/shared/styles/` | 公共文档样式、工具栏、字标 |
| `src/effects/` | Canvas 银杏与吹风手势 |
| `build/` | 配置编译与 HTML 首帧注入 |
| `scripts/`、`tests/` | 构建检查与回归测试 |

Profile 只导入公共文档样式，不依赖 Notes 的卡片、筛选和阅读弹窗样式。页面 CSS 必须保持在 HTML 头部直接加载，不能仅由应用 JS 引入，以避免未排版内容闪烁。Vite 构建必须保留原生 `light-dark()`（`build.cssTarget` 至少 Chrome 123 / Safari 17.5 / Firefox 120），因为主题由运行时 `color-scheme` 切换；Lightning CSS 针对旧目标的 polyfill 依赖静态媒体查询，无法跟随手动主题，且会把两个颜色拼成无效值。

落叶的形状、纹理和阴影绘制独立在 `effects/leaf-sprites.ts`，随机数生成在 `effects/random.ts`；`effects/leaves.ts` 保留运动、交互与画布生命周期。贴图替换和页面休眠共用同一套位图释放函数。

## 配置与首帧

`.config` 使用标准 JSON。`src/config/parse.ts` 在启动、构建和开发编译时验证字段、数值范围、链接协议及重复栏目 ID。Vite 插件把配置编译成普通对象，不将 JSON 原文和校验程序加载到浏览器，也无需访问远端配置接口。修改配置后开发页重新加载，生产发布需要重新构建。

`src/shared/bootstrap.js` 是无依赖的同步首帧逻辑，由构建插件内联到 HTML。它使用配置中的默认主题，即使浏览器拒绝本地存储也能正确显示。入口定位遮罩和内容页的跨页遮罩均有超时兜底。不要把这段脚本移到延迟执行的应用模块。

## 动画与清理

`shared/page-navigation.ts` 负责同源资源预热与一次性会话标记；`shared/page-transition.ts` 只负责目标页入场。只在实际点击入口时预热一个目标；脚本使用普通 preload 预取字节，不在首页预编译目标模块图。预热请求、节点和计时器在离开、超时或切换目标时清理。首页 Notes 的纸张先回正、收起背纸和文字，再按正面实际边界由不透明遮罩原位接替；原纸张隐藏后只放大遮罩，避免手机窄屏同时出现两个沿不同路径运动的矩形。文章入口维持有限的 3D 放大，避免放大整套嵌套图层。导航前固定遮罩最后一帧并取消临时动画，`pageshow` 恢复入口；不能提前移除最终遮罩。Notes 用约 1.4 秒将蓝色遮罩收拢到便签。首帧就隐藏根滚动条并取消 gutter 预留；应用接管时在同一任务中测量正常布局宽度，再冻结内容宽度、继续锁定滚动条。遮罩使用完整视口像素尺寸，完成或中断后恢复布局，避免 `100vw` 被 gutter 缩窄。收拢终点匹配真实便签的尺寸、倾角、颜色和圆角，目标便签在收拢期间保持透明且不播放额外位移动画；1.4 秒几何收拢完成后，在仍不透明的遮罩下恢复真实便签，再用 360ms 淡出遮罩，逐渐露出文字、折角和阴影。这样只在边界重合后交接，并避免两层同时半透明造成颜色闪变。Profile 不放大白色卡片，也不创建目标页遮罩：入口保持机器人和卡片原位，用 800ms 直接淡至与目标页一致的实际背景，目标页仅对视口内内容做 1400ms ease-in-out 淡入，保留正常滚动条与布局。减少动态效果、历史恢复、禁用响应动画时不播放交接。Notes 刷新不播放纸张交接；Profile 直接访问、刷新及会话存储不可用时也使用同样的淡入。

`shared/animation-group.ts` 统一阅读器、分类切换和资料展开的临时动画管理；保留各调用方的版本判断与清理时机，已结束但仍保留 fill 效果的动画也会在清理时取消。

分类动画作用于卡片外层，跟手弹簧作用于内层。新操作取消过时动画并清理离场副本。Profile 展开与收起同时过渡容器高度，连续点击从当前高度接续；完成后取消动画对象并移除临时裁剪。窗口变化、隐藏页面和离开页面都会结束临时动效。初次入场不为屏外内容创建动画。

阅读器的显示、关闭、正文、标题、焦点恢复由 `pages/notes/reader.ts` 负责。动画由 `reader-motion.ts` 负责；上一篇／下一篇先让旧文退出 240ms，再提交新正文并进入 420ms，同步过渡阅读框高度。快速切换或关闭会使过时的正文更新失效，不复制文章 DOM。窗口变化及离开页面时结束当前动画；关闭后清空隐藏正文。离开 Notes 进入历史缓存时也关闭弹窗并清空正文；返回后根据 hash 恢复文章及阅读位置，不增加历史记录或重播打开动画。阅读器不使用离站状态 `qp-entering`，不吹走或隐藏落叶；遮罩只缓慢变暗，不使用全屏动态背景模糊。滚动条使用细窄的主题色样式。

`navigation.ts` 管理阅读历史：从列表打开只 push 一条，前后文章用 replace；关闭自己创建的阅读记录时 back，直接访问深链接时则 replace 回列表。这样关闭后浏览器返回能回到之前页面，浏览器前进也能重新打开文章。检索输入合并到每帧最多一次更新。

## 内存与画布

银杏暂停且清空、标签页隐藏、页面退出时：停止请求帧，把画布回缩为 1×1 像素，并释放排序数组及贴图引用。仅保留少量叶片物理状态，冻结下落时间，恢复时按当前窗口、像素比和主题重新创建位图。窗口变化按比例保留现有位置，不重新随机生成。Profile 默认暂停，因此不创建全屏叶片缓冲，也不分配不可见的树影缓冲。前景默认受 1,048,576 像素预算限制（`leaves.pixelBudget`，可调 262,144–4,194,304），树影受 262,144 像素和 0.5 倍像素比限制；12 张贴图各 128×128。按 RGBA 单份像素数据估算，1080p / DPR 2 场景从原先约 42.55 MiB 降至不超过约 5.75 MiB，不包含浏览器内存和额外 GPU 合成缓冲。实测 1080p 下把前景预算从 2,097,152 降到 1,048,576，渲染进程约省 8–13 MiB、GPU 进程约省 9 MiB，合计约 17–22 MiB；具体取决于合成器实现。绘制排序数组每帧复用。

首次访问时各页统一逐片飘入；首页离开动画仅隐藏叶片，不再清场，历史返回保留原有位置。系统减少动态效果时直接展示静态画面。叶片静止后不继续 RAF，仅用一个定时器等待下一阵风或补充。默认运动帧率 60，允许小量时钟误差避免在 60Hz 显示器跳帧。补充叶片从落点附近上方慢慢飘落，落地前连续减速，避免横穿全屏和突然停转。

`shared/page-lifecycle.ts` 在标签页隐藏和 pagehide 时为根容器启用 content-visibility:hidden，并保存固有尺寸以保持页面高度；pageshow 恢复。落叶和首页动画另有页面活动状态，迟到的 ResizeObserver、主题或可见性回调不能唤醒缓存页。普通静止便签使用二维旋转，仅交互过程中使用三维变换，收敛后移除三维状态。

`shared/icons.ts` 按需导入 16 个图标和替换函数；开发模式不再从图标库总入口加载完整目录。更新列表时只替换新占位元素，已有 SVG（尤其主题图标）保留。

Notes 缓存保留当前可见卡片和有限的离屏卡片，最多为 `max(24, 可见卡片数)`；页面退出时清空缓存索引。弹簧状态在静止后释放，重置时清空引用。分类离场副本和动画对象在完成／中断时释放。`notes/filter.ts` 返回原列表下标，保留编号和纸张倾角，避免逐卡 `indexOf` 扫描；空搜索词直接按分类筛选，不再拼接并小写化全文。固定列表控件只在初始化时查询。正文仍支持全文搜索，因此 Markdown 数据保留在随笔页，不会加载到 Profile 页面。

这些措施减少应用持有的资源，并不等于浏览器进程 RSS 立刻回落；GPU 缓存、垃圾回收及历史页面缓存由浏览器管理。自动测试验证缓冲尺寸、状态和帧队列，真实内存峰值仍需浏览器 Performance / Memory 面板测量。

## 共用控件

三页普通页面内容和工具栏位于落叶层下方；落叶画布不接收指针事件，分类和工具栏仍可直接操作。原生阅读弹窗仍使用浏览器顶层，保留阅读操作。三页共用字标、主题与风按钮；斜杠后的当前页名称是普通 `span`，不可点击。主题偏好使用 `ginkgo-theme`。首页与 Notes 共用 `ginkgo-leaves-paused`；Profile 使用独立的初始暂停设置，不写入共享偏好。

风按钮单击清场，长按 700ms 暂停／恢复；触控、键盘和鼠标共享行为。取消、移动、失焦、隐藏页面都会取消长按计时。暂停标记及提示不由页面单独覆盖。

## 检查与发布

`npm run verify` 执行配置、内容、主题、手势、动效及资源生命周期测试，再进行类型检查、配置与内容校验、构建及产物检查。发布整个 `dist/`，支持域名根目录与子目录。

浏览器验收应覆盖三页往返、浅／深色与系统主题、禁用存储、快速筛选和阅读切换、长按恢复／暂停、窗口变化、历史返回、移动端和打印。自动测试不能替代像素和真实设备手感检查。

## 内存对比方法

Chrome 任务管理器中的“后退/向前缓冲页”是浏览器保留的历史页面，仍可能保留 DOM、JavaScript 和渲染进程。页面代码能释放自己持有的画布、动画及临时节点，不能承诺缓存页进程消失或 RSS 立即回落。不要用 unload 监听器破坏返回功能，也不把画布像素预算当作整个页面内存。

对比发布版本时运行 `npm run build` 后用 `npm run preview`，而非把 Vite 开发服务器和另一网站的生产版本直接比较。更新后关闭旧的本站标签页再重新打开，排除旧版本历史缓存。记录任务管理器的任务名称、内存占用和进程 ID；同一进程的多个任务行不应重复累加为独立进程。真实进程内存仍需要在浏览器中测量。
