# 银杏与风：实现与维护

## 页面入口

项目是 Vite 多页静态站点：`index.html` 对应引导页，`notes.html` 对应随笔页。两个 HTML 都直接声明各自的样式表，样式表再引入共用的 `controls.css`。不要将页面 CSS 改回仅通过 JavaScript 导入，否则开发模式可能再次出现未排版内容闪烁。

HTML 头部保留少量同步初始化代码，用于首帧主题、引导页定位等待和跨页遮罩。这部分必须先于应用模块执行；菜单、偏好同步等完整交互统一由 `theme.ts` 负责。

引导页完成 `initPortal()` 内的定位后解除加载状态。头部超时机制在主脚本失败时解除隐藏，避免永远等待。浏览器后退恢复缓存页面时，主题和落叶偏好会重新读取。

## 共用交互

| 模块 | 职责 |
| --- | --- |
| `preferences.ts` | 容错读写本地偏好，存储不可用不阻断页面 |
| `theme.ts` | 明暗模式、系统跟随、菜单关闭、跨标签页及历史恢复同步 |
| `wind-control.ts` | 点击／长按区分、键盘与触屏、取消手势、暂停标记与偏好 |
| `leaves.ts` | Canvas 银杏、风力、命中判断、生成与补充、可见性和节能 |
| `page-transition.ts` | 资源预热、一次性跨页标记、入场与清理 |
| `notes-motion.ts` | 分类重排、可取消过渡、便笺弹簧运动 |
| `reader-motion.ts` | 全文展开、收回和篇目切换 |

主题与落叶暂停分别使用 `ginkgo-theme` 和 `ginkgo-leaves-paused`。前者保留 light/dark/system；后者保存 true/false。状态由页面初始化、`storage` 与 `pageshow` 事件同步。

长按阈值为 700ms。短按只吹风；长按只切换暂停，不再触发一次短按。移出、拖动、触控取消、失焦、页面隐藏和按钮被禁用都会取消计时。暂停后旧叶子吹离画面，不再补充；窗口尺寸和主题变化不会重新生成。画面清空后停止请求动画帧。

## 导航与动画生命周期

引导页的 Notes 入口先展开蓝纸，导航提交后保留最后一帧。不能在 `location.assign()` 后立刻恢复原卡片，否则旧画面会短暂重现。`pageshow` 负责恢复浏览器缓存中的旧页。

同源 Notes 导航使用短时、一次性的会话标记交接颜色和速度。新页头部先铺同色遮罩，应用初始化完成后用约 1.4 秒收拢到蓝色便笺。直接访问、刷新、减少动态效果及外部链接不会播放该入场动画。遮罩有失败超时，动画结束、窗口改变和页面退出均执行清理。

所有应用内动画允许后续操作取消旧动画。分类动画作用于便笺外层，鼠标倾斜作用于内层，避免争用同一个 transform。滚动／失焦会释放跟手状态；触屏保留正常纵向滚动。

## 内容与发布

`notes-data.ts` 只负责 Vite 文件发现。`note-content.ts` 不依赖 DOM 或 Vite，供页面与构建检查复用。每篇 Markdown 一个文件，下划线开头的模板和 `draft: true` 不发布。当前 Markdown 是文档中列明的基础子集，不是完整 CommonMark 实现。

推荐流程：

```sh
npm ci
npm run dev
npm run verify
npm run preview
```

`verify` 包括手势、引擎、主题、内容与动效测试，以及类型检查、内容校验和生产产物检查。产物检查确保两页都提前加载 CSS、文件引用存在，并支持子目录部署。部署整个 `dist/`，不要只复制 HTML。

视觉验收使用实际浏览器确认：主页与随笔往返、直接打开文章链接、刷新与浏览器后退、明暗切换、长按暂停后切页／调整窗口、再次长按恢复，以及触屏滚动。自动测试使用可控事件和时钟验证状态逻辑，不能证明像素、帧率或不同浏览器的视觉表现完全一致。
